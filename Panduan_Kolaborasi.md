## **Project Overview**

This project aims to build a machine learning model that predicts the likelihood of an employee getting promoted, based on their profile, performance, and training history.

## **The main objectives are to:**

	•	Identify key factors that influence promotion outcomes.
	•	Provide data-driven insights to support HR decision-making.
	•	Present findings through visual analytics and structured reporting.

## **Collaboration workflow:**

### **#1 Clone the repository**
- *git clone https://github.com/heybayrepo/syntaxsociety.git*
- *cd syntaxsociety*

### **#2 Create your own branch**

- *git checkout -b your_branch_name*

#### **Branch naming conventions:**

- feature-name → new features or scripts
- eda-name → analysis or visualization work
- fix-name → bug fixes or corrections

**Example:** *git checkout -b eda-bayu*

### **#3 Commit your changes**

- *git add .*
- *git commit -m "Add Bayu's EDA notebook"*

### **#4 Sync and push**
- *git pull origin main*
- *git push origin your_branch_name*

### **#5 Create a Pull Request (PR)**

- Go to the Pull Requests → New pull request tab on GitHub
- Source: your branch
- Target: main
- Add a short description of your update

## **Collaboration Guidelines**
1. Always run git pull origin main before starting work.
2. Never push directly to main.
3. Use clear, descriptive commit messages.
4. Store large files (datasets, models, etc.) on Google Drive, not in the repo.
5. Discuss major code changes with the team before merging.
